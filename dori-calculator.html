How it works

Scene width = 2 × distance × tan(horizontal FOV ÷ 2)

Pixel density = horizontal pixels ÷ scene width

DORI distance = horizontal pixels ÷ (2 × required pixel density × tan(horizontal FOV ÷ 2))

For lens mode: horizontal FOV = 2 × atan(active sensor width ÷ (2 × focal length)). Angles are converted to radians internally.

Important: These are geometric estimates using commonly used IEC 62676-4 DORI thresholds (25, 62.5, 125 and 250 px/m). They assume a rectilinear lens, full active image width and a perpendicular target plane. Use the manufacturer's actual horizontal FOV where available. Sensor format presets use approximate active widths, not exact physical dimensions. Fisheye lenses, cropping, lighting, compression and motion can change real performance. Identification is not guaranteed.
